# 🪪 Carnet Empresarial — Prototipo de credencial digital

> Prototipo web de un **carnet empresarial de doble cara**, desarrollado para presentar visualmente la identidad y los datos de contacto de un colaborador mediante una interfaz personalizada.

## 📌 Sobre el proyecto

**Carnet Empresarial** es un ejercicio de maquetación web que representa el frente y el reverso de una credencial de identificación. Su propósito es explorar la organización visual de datos, la tipografía y los estilos CSS aplicados a un formato de carnet.

El prototipo utiliza información ficticia de una empresa y un personaje. **No implementa verificación real de identidad**, autenticación ni almacenamiento de datos: la insignia «VERIFIED» es un elemento visual.

---

## ✨ Características

- 🪪 **Dos caras visibles:** diseño frontal y reverso de la credencial.
- 👤 **Frente:** nombre de empresa, avatar, cargo, nombre, información personal e insignia visual.
- 📇 **Reverso:** datos de identificación de ejemplo, grupo sanguíneo, ciudad, tecnología favorita, enlace a GitHub y correo ficticio.
- 🎨 **Diseño personalizado:** fondos degradados, variables CSS, tipografías y distribución con Flexbox.
- 🔗 **Recursos externos:** imagen de avatar, fuentes de Google Fonts e iconos de Font Awesome.

---

## 🧰 Tecnologías utilizadas

- **HTML5:** estructura y contenido de la credencial.
- **CSS3:** colores, tipografía, distribución y estilos visuales.
- **Google Fonts:** Cormorant Infant, PT Sans Narrow, Metamorphous y Economica, cargadas desde el HTML.
- **Font Awesome:** iconos de tecnología, GitHub y correo electrónico.

No se utiliza JavaScript ni un framework de frontend en la versión incluida.

## 🖥️ Ejecutar el proyecto localmente

### 1. Clonar el repositorio

```bash
git clone https://github.com/SneyderRodriguez/CARNET-EMPRESARIAL.git
```

### 2. Entrar en la carpeta

```bash
cd CARNET-EMPRESARIAL
```

### 3. Abrir el proyecto

Abre `index.html` en tu navegador. También puedes utilizar la extensión **Live Server** de Visual Studio Code. No es necesario instalar Node.js ni dependencias. Para visualizar correctamente las fuentes, los iconos y el avatar externos, se necesita conexión a Internet.
